# Blog photos

Create one folder per post using the same short slug as its post filename,
for example `assets/images/blog/sharpening-a-chisel/`. Keep the cover and
in-article photos together. Use descriptive filenames such as `cover.jpg` and
`sharpening-angle.jpg`, and link to them from the post's Markdown file.

Use optimized JPG or WebP for photographs and PNG or SVG for graphics. Add
meaningful alt text to every informative image.
