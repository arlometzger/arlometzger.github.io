# Project photos

Create one folder per project using the same short slug as its collection file,
for example `assets/images/projects/wooden-stool/`. Keep that project's cover
and detail photos together. Use descriptive filenames such as `cover.jpg` and
`joinery-detail.jpg`, and link to them from the project's Markdown file.

Use optimized JPG or WebP for photographs and PNG or SVG for graphics. Add alt
text in the project's front matter or Markdown so the images are accessible.
