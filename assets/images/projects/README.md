# Project photos

Create one folder per project inside its craft folder, using the same short
slug as the collection file. For example, photos for
`_projects/woodworking/wooden-stool.md` go in
`assets/images/projects/woodworking/wooden-stool/`. Keep that project's photos
together. Use descriptive filenames such as `finished-front.jpg` and
`joinery-detail.jpg`, and link to them from the project's Markdown file.

Use optimized JPG or WebP for photographs and PNG or SVG for graphics. Add alt
text in the project's front matter or Markdown so the images are accessible.

VS Code's Path Intellisense workspace recommendation and settings map site-root
paths such as `/assets/images/...` to this repository's `assets/` directory.
